# Module « Livraisons » (exemple)

Suivi des livraisons à domicile. Sert aussi de **modèle** pour créer un module POS Wan :
copiez ce dossier, renommez-le (ex. `addons/pressing/`), changez `code`, `name` et le
contenu, puis installez-le depuis **Gestion → Modules complémentaires**.

Voir `docs/MODULES.md` à la racine de POS Wan pour la documentation complète.
