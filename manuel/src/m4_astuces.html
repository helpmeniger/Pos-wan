Taper rapidement au clavier

La saisie tactile (taper sans regarder ses doigts) repose sur une idée simple : chaque doigt a sa zone sur le clavier. Avec un entraînement régulier, vos doigts mémorisent l’emplacement des touches (la mémoire musculaire).

La bonne posture

  • Asseyez-vous le dos droit.
  • Coudes pliés à angle droit.
  • Tête légèrement inclinée vers l’avant, face à l’écran.
  • 45 à 70 cm entre les yeux et l’écran.
  • Épaules, bras et poignets détendus. Les poignets peuvent effleurer le bord du clavier, mais ne prenez pas appui dessus.

La position des doigts

  • Sur un clavier AZERTY, les doigts reposent sur la rangée de repos : main gauche sur Q S D F, main droite sur J K L M. Les touches F et J portent un petit relief pour les retrouver sans regarder.
  • N’appuyez sur une touche qu’avec le doigt qui lui est réservé, puis revenez toujours à la position de repos.
  • La touche Maj s’enfonce avec l’auriculaire de la main opposée à la lettre.
  • La barre Espace se tape avec le pouce.

La vitesse

  • Au début, privilégiez la précision plutôt que la vitesse. La vitesse viendra avec l’habitude.
  • Gardez un rythme régulier entre les frappes.
  • Faites des pauses quand vous multipliez les erreurs.
AstuceEntraînez-vous 10 minutes par jour avec un site gratuit de dactylographie (recherchez « cours de dactylographie AZERTY gratuit »). Pour un long texte, la dictée vocale (Windows + H) peut aussi vous faire gagner du temps.

Transférer des fichiers : clé USB et téléphone

Copier des fichiers sur une clé USB ou un disque externe

  1. Branchez la clé USB. Elle apparaît dans l’Explorateur de fichiers, sous Ce PC, avec une lettre (par exemple E:).
  2. Sélectionnez les fichiers à copier, puis Ctrl + C (ou clic droit › Copier).
  3. Ouvrez la clé USB, cliquez dans un espace vide, puis Ctrl + V (ou clic droit › Coller).
  4. Autre méthode : faites glisser les fichiers sur l’icône de la clé dans le volet de navigation.
  5. Avant de retirer la clé : clic droit sur la clé › Éjecter. Attendez le message de confirmation.
AttentionUne clé USB se perd ou s’abîme facilement : ne la considérez jamais comme votre seule sauvegarde (règle 3-2-1, Partie 3, chapitre 4). Analysez les clés inconnues avec l’antivirus avant de les ouvrir.

Transférer des fichiers avec un téléphone Android

  1. Déverrouillez votre téléphone et reliez-le à l’ordinateur avec un câble USB.
  2. Sur le téléphone, touchez la notification Recharge de l’appareil via USB.
  3. Sous Utiliser la connexion USB pour, sélectionnez Transfert de fichiers.
  4. Le téléphone apparaît dans l’Explorateur. Ouvrez-le (dossier DCIM pour les photos) et copiez-collez ou glissez les fichiers.
  5. Quand vous avez terminé, éjectez le téléphone dans Windows, puis débranchez le câble.
Sans câble
  • Lien avec le mobile (Phone Link, inclus dans Windows 11) : voir ses photos, ses SMS et ses notifications sur l’ordinateur.
  • Partage à proximité : envoyer un fichier par Wi-Fi ou Bluetooth à un appareil proche.
  • Le cloud (Google Photos, OneDrive) ou WhatsApp sur ordinateur, pour les petits fichiers.

Installer et désinstaller une application

Installer depuis le Microsoft Store (recommandé)

  1. Ouvrez le Microsoft Store depuis le menu Démarrer.
  2. Recherchez l’application (par exemple « WhatsApp » ou « VLC »).
  3. Cliquez sur Obtenir ou Installer. L’application apparaît ensuite dans le menu Démarrer.

Installer depuis le site officiel

Certains logiciels s’installent depuis le site de leur éditeur. Exemple pour le navigateur Google Chrome : allez sur google.com/chrome et cliquez sur Télécharger Chrome.

  1. Le fichier d’installation, au format .exe ou .msi (« point EXE »), est enregistré dans le dossier Téléchargements.
  2. Double-cliquez dessus. Windows demande l’autorisation d’apporter des modifications : cliquez sur Oui si vous faites confiance à la source.
  3. Suivez les instructions de l’assistant d’installation (Suivant, Accepter, Installer, Terminer). Lisez chaque écran : décochez les logiciels supplémentaires proposés que vous ne voulez pas.
AttentionN’installez jamais de logiciels « piratés » ou « crackés » : ils contiennent très souvent des virus et des logiciels espions. Si Windows affiche « Windows a protégé votre ordinateur », ne forcez pas l’installation sans être certain de la source.

Désinstaller une application

  • Par le menu Démarrer : clic droit sur l’application › Désinstaller.
  • Par les Paramètres : Windows + I › Applications › Applications installées, cliquez sur ⋯ à côté de l’application, puis sur Désinstaller.
  • Par le Panneau de configuration (méthode classique) : recherchez « Panneau de configuration » › Programmes et fonctionnalités, clic droit sur le programme › Désinstaller.

Exercice 1 · Le bureau et la barre des tâchesdébutant

Exercice 2 · L’Explorateur de fichiersdébutant

  2. Parcourez les dossiers Bureau, Documents, Téléchargements et Images.
  3. Quelles lettres désignent les lecteurs de votre ordinateur ?
  4. Faites un clic droit sur le disque C: › Propriétés. Notez l’espace utilisé et l’espace libre.
Exercice 3 · Le menu Démarrerdébutant

  2. Faut-il fermer Paint avant de lancer la Calculatrice ? Pourquoi ?

Exercice 4 · Dossiers et fichiersintermédiaire
  1. Sur le bureau, créez un dossier nommé Mes exercices.
  2. Dans ce dossier, créez deux sous-dossiers : Drapeau du Niger et Personnel.
  3. Téléchargez le drapeau du Niger à l’adresse upload.wikimedia.org/wikipedia/commons/f/f4/Flag_of_Niger.svg et enregistrez-le dans le dossier Drapeau du Niger.
  4. Ouvrez le Bloc-notes, écrivez votre nom et enregistrez le fichier sous le nom mon nom dans le dossier Personnel.
Exercice 5 · Manipuler les fenêtresintermédiaire
  1. Ouvrez l’Explorateur de fichiers. Agrandissez la fenêtre, puis réduisez-la : elle se range dans la barre des tâches. Cliquez sur son icône pour la réafficher.
  2. Cliquez sur Restaurer pour réduire sa taille.
  3. Dans le volet de navigation, cliquez sur Bureau.
  4. Testez les affichages : Afficher › Grandes icônes, Liste, Détails.
  5. Fermez la fenêtre.
Exercice 6 · Déplacer et redimensionnerintermédiaire
  1. Ouvrez l’Explorateur. Si la fenêtre est en plein écran, cliquez sur Restaurer.
  2. Déplacez la fenêtre à plusieurs endroits en faisant glisser sa barre de titre.
  3. Placez le pointeur sur le bord droit (double flèche ↔) et faites glisser le bord.
  4. Faites glisser le coin inférieur droit pour réduire la fenêtre de moitié, puis rendez-lui sa taille d’origine.
Exercice 7 · Le multitâcheavancé
  1. Ouvrez 5 fenêtres. Passez de l’une à l’autre avec Alt + Tab, puis avec la Vue des tâches.
  2. Disposez 3 fenêtres avec les dispositions d’ancrage (Windows + Z).
  3. Réduisez toutes les fenêtres d’un seul raccourci, puis faites-les réapparaître.
  4. Fermez toutes les fenêtres une par une, puis redémarrez l’ordinateur.
