Glossaire

Adresse IP : numéro qui identifie un appareil sur un réseau ou sur Internet.

Agent IA : assistant d’intelligence artificielle capable d’enchaîner plusieurs actions pour accomplir une tâche.

Algorithme : suite d’étapes précises pour résoudre un problème.

Antivirus : logiciel qui détecte et supprime les programmes malveillants.

Application (appli) : logiciel, en particulier sur téléphone ou tablette.

Arobase (@) : caractère qui sépare le nom d’utilisateur et le domaine dans une adresse e-mail.

Arrière-plan : image ou couleur affichée au fond du bureau.

Barre des tâches : bande en bas de l’écran de Windows (Démarrer, applications, heure).

Binaire : système de numération qui n’utilise que 0 et 1.

BIOS / UEFI : petit programme qui démarre l’ordinateur avant le système d’exploitation.

Bit : plus petite unité d’information (0 ou 1).

Bluetooth : liaison sans fil à courte portée (écouteurs, souris, téléphone).

Bogue (bug) : erreur dans un programme.

Bureau : écran principal de Windows après l’ouverture de session.

Câble Ethernet (RJ45) : câble de connexion à un réseau filaire.

Capture d’écran : image de ce qui est affiché à l’écran.

Carte mère : circuit principal qui relie tous les composants de l’ordinateur.

Cellule : case d’un tableau Excel, à l’intersection d’une ligne et d’une colonne.

Clé USB : petit support de stockage amovible qui se branche sur un port USB.

Cloud (nuage) : stockage et services accessibles par Internet.

Code source : texte d’un programme écrit par un programmeur.

Compte utilisateur : identité (nom et mot de passe) qui permet d’accéder à un ordinateur ou à un service.

Cookie : petit fichier qu’un site enregistre dans le navigateur pour se souvenir de vous.

Copier-coller : dupliquer un élément à un autre endroit.

Corbeille : dossier où vont les éléments supprimés avant leur suppression définitive.

CPU (processeur) : composant qui exécute les instructions ; le « cerveau » de l’ordinateur.

Curseur (pointeur) : flèche qui se déplace à l’écran avec la souris.

Cybersécurité : protection des ordinateurs, des données et des personnes contre les attaques.

Disque dur (HDD) : support de stockage permanent à plateaux tournants.

Disquette : ancien support de stockage magnétique (1,44 Mo), aujourd’hui disparu.

Données : informations brutes (textes, chiffres, images) traitées par l’ordinateur.

Dossier : classeur qui permet de ranger des fichiers.

Double authentification (2FA) : connexion qui demande un mot de passe et un second code.

DVD / CD-ROM : disque optique pour stocker de la musique, des films ou des données.

E-mail (courriel) : message électronique envoyé par Internet.

Écran tactile : écran que l’on commande avec le doigt.

Explorateur de fichiers : application de Windows qui permet de parcourir et de ranger ses fichiers.

Extension : lettres après le point dans le nom d’un fichier ; elles indiquent son type (.docx, .pdf).

Fenêtre : zone rectangulaire qui affiche une application ou un dossier.

Fibre optique : câble qui transporte les données par la lumière, très rapidement.

Fichier : ensemble d’informations enregistré sous un nom.

Filigrane : texte ou image en transparence derrière le contenu d’une page.

Fonction (Excel) : formule toute prête, comme SOMME ou MOYENNE.

Formule (Excel) : calcul qui commence par le signe =.

Fournisseur d’accès (FAI) : entreprise qui fournit la connexion à Internet.

Gigaoctet (Go) : 1 000 mégaoctets.

GPS : système de localisation par satellites.

GPU (carte graphique) : composant qui calcule l’affichage ; très utilisé pour l’IA.

Hallucination (IA) : information fausse inventée par une intelligence artificielle.

Hameçonnage (phishing) : faux message qui cherche à voler un mot de passe, un code ou de l’argent.

Hardware (matériel) : partie physique de l’ordinateur.

Historique : liste des pages consultées dans un navigateur.

Hypertrucage (deepfake) : fausse image, vidéo ou voix créée par l’IA.

Icône : petite image qui représente une application, un fichier ou un dossier.

Imprimante : périphérique de sortie qui imprime sur papier.

Intelligence artificielle (IA) : programmes capables d’apprendre, de comprendre le langage, de reconnaître des images ou de créer du contenu.

IA générative : IA qui crée du texte, des images, du son ou du code.

Internet : réseau mondial qui relie des milliards d’appareils.

Kilooctet (Ko) : 1 000 octets.

Lien (hyperlien) : texte ou image sur lequel on clique pour aller vers une autre page.

Linux : système d’exploitation libre et gratuit.

LLM : « grand modèle de langage », programme d’IA qui comprend et écrit du texte.

Logiciel (software) : programme qui apporte des fonctionnalités à l’ordinateur.

Logiciel malveillant : programme conçu pour nuire (virus, logiciel espion, rançongiciel).

Mégaoctet (Mo) : 1 000 kilooctets.

Menu contextuel : menu qui s’ouvre avec le clic droit.

Microprocesseur : voir CPU.

Mise à jour : nouvelle version d’un logiciel qui corrige des failles et apporte des améliorations.

Mobile money : service de paiement et de transfert d’argent par téléphone.

Modem / box : appareil qui relie votre réseau à Internet.

Mot de passe : code secret qui protège un compte.

Moteur de recherche : site qui trouve des pages Web à partir de mots-clés (Google, Bing).

Navigateur : logiciel qui affiche les pages Web (Chrome, Edge, Firefox, Safari).

Octet : unité de mesure de l’information, égale à 8 bits.

Onduleur : appareil qui protège l’ordinateur des coupures de courant.

Onglet : page ouverte dans un navigateur, ou rubrique du ruban de Word et d’Excel.

Ordinateur : machine électronique programmable qui traite des données.

Pare-feu : protection qui filtre les connexions réseau.

Partage de connexion : utilisation de l’Internet du téléphone sur un autre appareil.

PDF : format de document qui conserve la mise en page sur tous les appareils.

Périphérique : matériel relié à l’ordinateur (clavier, souris, imprimante…).

Pièce jointe : fichier envoyé avec un e-mail.

Pixel : point élémentaire d’une image ou d’un écran.

Plage de cellules : groupe de cellules, par exemple A1:B10.

Port : prise de l’ordinateur (USB, HDMI…).

Presse-papiers : mémoire temporaire qui garde ce que l’on a copié.

Programme : suite d’instructions exécutées par l’ordinateur.

Prompt : demande écrite à une intelligence artificielle.

QR code : code-barres carré lisible par l’appareil photo d’un téléphone.

RAM (mémoire vive) : mémoire de travail temporaire, effacée à l’extinction.

Raccourci : lien vers un fichier ou une application (icône avec une flèche).

Raccourci clavier : combinaison de touches qui lance une commande.

Rançongiciel : logiciel malveillant qui bloque vos fichiers et réclame une rançon.

Réseau : ensemble d’appareils reliés entre eux.

Réseau social : site ou application de partage (Facebook, TikTok, LinkedIn…).

ROM (mémoire morte) : mémoire permanente qui contient les instructions de démarrage.

Routeur : appareil qui dirige les données entre les réseaux.

Ruban : barre de commandes en haut de Word et d’Excel.

Sauvegarde : copie de sécurité de ses fichiers.

Scanner : périphérique qui numérise un document papier.

Serveur : ordinateur qui fournit des services ou des sites à d’autres appareils.

Session : période d’utilisation d’un ordinateur avec son compte.

Site Web : ensemble de pages accessibles par Internet.

Smartphone : téléphone mobile qui fonctionne comme un petit ordinateur.

Spam (pourriel) : message publicitaire ou frauduleux non désiré.

SSD : support de stockage rapide sans pièce mobile.

Système d’exploitation : logiciel de base qui fait fonctionner l’appareil (Windows, Android…).

Tableau croisé dynamique : résumé automatique de données dans Excel.

Tablette : appareil mobile à grand écran tactile.

Téléchargement : copie d’un fichier d’Internet vers son appareil.

Téraoctet (To) : 1 000 gigaoctets.

Traitement de texte : logiciel pour écrire et mettre en forme des documents (Word).

Tableur : logiciel pour faire des tableaux et des calculs (Excel).

Unité centrale : boîtier qui contient les composants principaux de l’ordinateur.

URL : adresse d’une page Web.

USB : type de prise très répandu (USB-A, USB-C).

Virus : programme malveillant qui se propage d’un appareil à l’autre.

Visioconférence : réunion à distance avec image et son (Meet, Zoom, Teams).

Web (World Wide Web) : ensemble des sites accessibles par Internet.

Webcam : caméra reliée à l’ordinateur.

Wi-Fi : connexion sans fil à un réseau et à Internet.

Windows : système d’exploitation de Microsoft.

Zone de notification : partie droite de la barre des tâches (réseau, son, heure).
