# Pos-wan — Niger Parcelles

Ce dépôt contient **Niger Parcelles**, une application web de cartographie et de gestion foncière
du Niger fonctionnant sous WampServer (Apache, PHP 8, MySQL/MariaDB).

➡️ Le code, le guide d'installation et la documentation se trouvent dans
[`niger_parcelles/`](niger_parcelles/README.md).

Installation rapide : copier le dossier `niger_parcelles` dans `C:\wamp64\www\`, puis ouvrir
`http://localhost/niger_parcelles/` et suivre l'installateur.
