Ports utilisés par WampServer

Apache (le serveur web) utilise le port 80 ; MySQL / MariaDB utilisent 3306, 3307 ou 3308. Si un autre programme les occupe (IIS, Skype, un autre serveur…), WampServer reste orange. L'installateur peut l'arrêter et l'empêcher de redémarrer.

Paquet d'installation

Le zip « pos-wan install » qui contient : les vcredist (2008 à 2022), WampServer, l'installateur de Google Chrome et POS-Marwa-x.x.x.zip.

Options

L'installateur s'exécute avec les droits administrateur (accordés une seule fois au lancement). Il ne désactive jamais le contrôle de compte (UAC), l'antivirus ni le pare-feu de Windows : il n'ajoute que les autorisations nécessaires à POS Marwa.
